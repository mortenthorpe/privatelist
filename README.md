# PrivateList
2026 - In-progress - Fully GDPR and data-privacy respecting personal items-list shareable with select other users, easily so by QR code etc.

# PrivateList - Main concepts #
* Conceptually a on-device (smartphone, computer) browser-based online-accessible application to retain data:
   - E.g.: A personal TO-DO list, totally traditionally so, with no sharing of the items
   - E.g. The TODO-list extended to provide TODO list items as shared collations of new shared TODO-items, while respecting privacy, offering granular control to items by data-expiry, revocation by the list-owner (source) etc.
   - An online centralized shared repository of items that can be added to the lists of each user - Without exposing the relationship between the user and the items they hold in there TODO-lists - e.g.: Fulfillment of data privacy legislation by design, not by added complexity or gateways and dedicated security programming in-place.
